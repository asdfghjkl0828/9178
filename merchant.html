还没配置代理？点开看部署指引（约 3 分钟）
  1. 申请 WeGame API Key：登录 https://rocom.shallow.ink/ → 开发者平台 / API Key 页面申请（需 WeGame 作用域）。
  2. 部署免费代理（Cloudflare Worker）：登录 dash.cloudflare.com → Workers → 新建 Worker → 把本仓库 worker.js 内容粘贴进去并部署。
  3. 绑定 Key（关键·安全）：Worker Settings → Variables 添加环境变量 API_KEY = 你的 Key，并设为 Secret。Key 只放这里——不要发到聊天、也不要写进任何前端代码或仓库。worker.js 读的是环境变量，本身不含 Key，可安全提交。
  4. 把部署得到的地址（如 https://rocom-proxy.xxx.workers.dev）发给我，我填进本页 WORKER_URL 常量并推送，真实货架即可显示。
  5. 为什么必须代理：后端 wegame.shallow.ink 无 CORS 头，且 Key 一旦进前端就会公开泄露并被限流，所以必须由服务端代理转发。
