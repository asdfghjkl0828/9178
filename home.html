数据怎么来的？（点击展开）
  1. 本页由 GitHub Actions 定时任务（每 15 分钟）按预设 UID 列表自动抓取，存为 data/home_<uid>.json，前端直接读取——无需代理、大陆可访问。
  2. 想查某个同学？把 TA 的洛克 UID（和昵称）发给助理，助理加入 data/uids.json 并推送，约 15 分钟内自动出数据。
  3. WeGame API Key 仅存于 GitHub 仓库 Secrets，不进前端。
没有同学？把 TA 的 UID 发给助理加入预设列表，约 15 分钟自动同步。
字段说明
