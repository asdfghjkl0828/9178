怎么增加自动追踪的 UID？（点击展开）
  1. 自动追踪的 UID 写在仓库的 data/uids.json（目前默认 [5678116]）。
  2. 想加同学：把 UID 加进这个数组（如 [5678116, 1234567]），提交后下次自动抓取就会包含他。
  3. 注意免费额度每天 3 次 / IP，所以 uids.json 里最多放 3 个 UID 才能每天都被抓到。
  4. 数据每小时（北京时间整点后 7 分）更新一次；植物成熟 / 生蛋倒计时是当天快照，精确到分钟以游戏内为准。
  5. 想让「⚡ 实时查询」在纯 GitHub Pages 下也能用：需一次性部署云端代理（详见本页底部「怎么部署实时代理」说明）。部署后页面自动走代理，无需开任何程序。
怎么部署⚡实时查询的云端代理（一次性，免费用）
  1. 实时查询需要一个中国可达、带 CORS 的免费代理转发 rocodex（纯 GitHub Pages 无后端，且 rocodex 不发跨域头，浏览器直连会被拦）。
  2. 推荐 Cloudflare Pages（你已有 CF 账号）：本仓库已含 proxy/ 文件夹（functions/home.js 即代理）。本地装好 wrangler 后执行两行命令：
    npx wrangler login
    npx wrangler pages deploy proxy --project-name roco-proxy
  3. 部署完会得到形如 https://roco-proxy.pages.dev 的地址（项目名可自定义）。把地址告诉页面：在网址后加 ?proxy=https://你的地址.pages.dev 打开一次即记住（或改 home.html 顶部的 RT_PROXY_DEFAULT）。
  4. 之后在 GitHub Pages 打开本页，输 UID 点「查询最新」就是当前实时数据，零成本、免积分，纯网页操作。
  5. 若 *.pages.dev 在你的网络被拦，可改用 Vercel（vercel.app，同样免费、中国可达）：把 proxy/functions/home.js 复制到 api/home.js 部署即可（逻辑一致）。
  6. 代理每次请求都用新访客身份，≈无限次免费实时；若多人共用触发 IP 级限流，稍降频率即可。
